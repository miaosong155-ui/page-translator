A Short Guide to Reading Foreign Pages

Reading a website written in another language is often harder than it looks. You have to deal with unfamiliar vocabulary, dense paragraphs, and technical terms that do not translate cleanly.

Why plain translation matters

A good translation keeps the page layout intact. Headings stay headings, tables stay tables, and the reading flow does not break. That is the whole point of translating in place rather than opening a separate window.

Inline emphasis, strong text, and links must survive the process without turning into a single wall of text.

Keep the original around, so you can always switch back when a sentence feels wrong.

A code sample that should not be translated

const answer = items.map(x => x * 2).filter(Boolean);
console.log("Hello, world", answer);

Inline code such as npm install should also stay as it is.
